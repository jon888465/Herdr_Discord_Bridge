# 範例：登入逾時後頁面顯示空白（Mantis 0001234）

## Mantis 欄位

| 欄位 | 值 |
|---|---|
| 編號 | 0001234 |
| 專案／分類 | example-project／前端 |
| 狀態 | 新建（new） |
| 嚴重度 | 次要（minor） |
| 優先順序 | 一般（normal） |
| 重現率 | 每次（always） |
| 版本 | 1.4.2 |
| 平台／作業系統 | 桌面瀏覽器／macOS |

## 描述

使用者閒置超過 30 分鐘後再操作，頁面變成空白，沒有任何錯誤訊息。

## 重現步驟

1. 登入系統。
2. 閒置 30 分鐘以上。
3. 點選任一選單項目。

## 預期結果

顯示「登入逾時」提示並導向登入頁。

## 實際結果

頁面空白，瀏覽器主控台出現 401 回應。

## 補充資訊

僅在使用 Safari 時發生；Chrome 會正常導向登入頁（回報者自述，未獨立驗證）。

## Mantis 備註（摘要）

- 回報者補充：清除 cookie 後可恢復。
- 負責人尚未指派。

## 驗收條件

以下由 Agent 依描述推測，**需要使用者確認**：

- [ ] 閒置逾時後操作，會顯示「登入逾時」提示並導向登入頁。
- [ ] Safari 與 Chrome 行為一致。
- [ ] 補上對應的自動化測試。

## 待確認

- 逾時的實際門檻是否為 30 分鐘。
- 是否只影響 Safari，還是 Chrome 也會在特定條件下發生。
- 空白頁是前端沒處理 401，還是後端沒有回傳導向。
